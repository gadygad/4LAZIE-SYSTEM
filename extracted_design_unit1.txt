Network Design Methodology: 
Network Design Methodology is a structured approach to planning, designing, and 
implementing computer networks so they meet business, technical, and performance 
requirements. Instead of building networks ad hoc, this methodology ensures scalability, 
reliability, security, and cost-effectiveness. 
 1. Requirements Analysis 
This is the foundation. You identify: 
 Business goals (e.g., growth, services, budget)  
 User requirements (number of users, applications)  
 Technical needs (bandwidth, security, uptime)  
 Constraints (cost, time, existing infrastructure)  
 2. Logical Network Design 
Focus on what the network should do (not physical devices yet): 
 Network topology (star, mesh, hybrid)  
 IP addressing scheme  
 Routing protocols (OSPF, BGP, etc.)  
 Network segmentation (VLANs, subnets)  
 Security architecture (firewalls, ACLs)  
 3. Physical Network Design 
Now define how to implement the logical design: 
 Hardware selection (routers, switches, cables)  
 Physical topology (rack layout, cabling paths)  
 Data center or site layout  
 Redundancy (backup links, failover systems)  
 4. Implementation (Deployment) 
 Install devices and configure them  
 Apply IP addressing and routing  
 Set up security policies  
 Integrate with existing systems  
 5. Testing and Validation

Hierarchical Network Model 
The Hierarchical Network Model is a layered approach used in designing computer 
networks. 
It divides the network into different layers, where each layer performs specific functions. 
This model helps to: 
 Improve network performance 
 Simplify management 
 Increase scalability 
 Enhance security 
 Reduce network problems 
The most common hierarchical model has three layers: 
1. Core Layer 
2. Distribution Layer 
3. Access Layer

1. Access Layer 
The Access Layer is the lowest layer of the network. It is the layer where end devices 
connect to the network. 
Functions 
 Connects PCs, printers, IP phones, and wireless devices 
 Provides network access to users 
 Controls user access and security 
 Supports VLANs and port security 
Devices Used 
 Access switches 
 Wireless access points 
Example 
In a college: 
 Computer lab PCs connect to access switches 
 Staff room systems connect through this layer 
2. Distribution Layer 
 The Distribution Layer acts as the middle layer. 
 It connects the access layer to the core layer.

Design Objectives in Network Design 
Design Objectives are the goals and requirements that guide the planning and 
implementation of a computer network. 
These objectives ensure that the network operates efficiently, securely, and reliably 
according to organizational needs. 
 
 
 
 
 
 
 
 
 
1. Scalability 
Scalability means the network should support future growth without major redesign.

Scalability Concepts in Computer Networks 
Scalability is the ability of a network to grow and handle increasing users, devices, 
applications, and traffic without reducing performance or requiring complete redesign. 
A scalable network can expand smoothly as organizational requirements increase. 
 
 Definition 
Scalability refers to: 
“The capability of a network system to support future growth efficiently.” 
This growth may include: 
 More users  
 More devices  
 More branches  
 Increased bandwidth  
 New services and applications

 Importance of Scalability 
Scalability is important because organizations continuously grow. 
Without scalability: 
 Network congestion increases  
 Performance decreases  
 Maintenance becomes difficult  
 Costs become higher  
 Types of Scalability 
1. Vertical Scalability (Scale-Up) 
Vertical scalability means increasing the capacity of existing devices. 
Methods 
 Upgrading CPU  
 Increasing RAM  
 Adding storage  
 Using higher-capacity switches or routers  
Example 
Replacing a 24-port switch with a 48-port switch. 
Advantages 
 Simple implementation  
 Less configuration changes  
Disadvantages 
 Hardware upgrade cost is high  
 Limited expansion capability  
2. Horizontal Scalability (Scale-Out) 
Horizontal scalability means adding more devices to the network. 
Methods 
 Adding switches  
 Adding routers  
 Adding servers  
 Expanding network segments  
Example 
Adding another switch to support a new computer lab.

Network Documentation 
Network Documentation is the process of recording all important information about a 
computer network. 
It includes details about: 
 Network devices  
 IP addresses  
 Configurations  
 Topology diagrams  
 Security settings  
 Maintenance procedures  
Proper documentation helps administrators understand, manage, troubleshoot, and 
expand the network efficiently. 
 
 Definition 
Network Documentation is a collection of records, diagrams, configurations, and 
technical details related to a network infrastructure.
