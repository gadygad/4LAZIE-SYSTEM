IPv4 & IPv6 Design 
What is IP Address? 
An IP Address (Internet Protocol Address) is a unique address used to identify devices 
in a network. 
Example: 
 Computer  
 Mobile phone  
 Printer  
 Server  
Two main versions: 
1. IPv4 (Internet Protocol Version 4)  
2. IPv6 (Internet Protocol Version 6) 
1. IPv4 Design 
Introduction 
IPv4 is the fourth version of Internet Protocol and the most widely used protocol. 
Features 
 32-bit address  
 Written in decimal format  
 Divided into 4 octets  
 Supports about 4.3 billion addresses  
Example 
192.168.1.1 
IPv4 Structure 
IPv4 uses 32 bits. 
Example: 
11000000.10101000.00000001.00000001 
Decimal form: 
192.168.1.1

2. IPv6 Design 
Introduction 
IPv6 was developed to solve IPv4 address shortage. 
Features 
 128-bit address  
 Huge number of addresses  
 Better security  
 Faster routing  
Example 
2001:0db8:85a3:0000:0000:8a2e:0370:7334 
Short form: 
2001:db8:85a3::8a2e:370:7334

IPv6 Structure 
IPv6 uses 128 bits. 
It is divided into 8 groups. 
Example: 
2001:0db8:0000:0000:0000:ff00:0042:8329 
IPv6 Advantages 
 Very large address space

 No NAT required

 Complex implementation  
 Expensive upgrade

Subnetting Techniques 
What is Subnetting? 
Subnetting is the process of dividing one large network into smaller networks called 
subnets. 
It improves: 
 Network performance  
 Security  
 Traffic management  
 Efficient IP address usage  
 
Why Subnetting is Needed? 
Without subnetting: 
 Large broadcast traffic  
 Network congestion  
 Wastage of IP addresses  
 Difficult network management  
With subnetting: 
 Better organization  
 Faster communication  
 Improved security  
Basic Terms

Routing Protocols Overview 
What is Routing? 
Routing is the process of transferring data packets from one network to another 
network using a router. 
Routers select the best path for data communication.

What is a Routing Protocol? 
A Routing Protocol is a set of rules used by routers to: 
 Share network information  
 Discover routes  
 Select best paths  
 Update routing tables  
Functions of Routing Protocols 
 Path determination  
 Route maintenance  
 Network discovery  
 Loop prevention  
 Fast communication  
Types of Routing 
1. Static Routing 
Routes are manually configured by administrator. 
Advantages 
 Simple  
 Secure  
 No routing overhead  
Disadvantages 
 Difficult in large networks  
 No automatic updates  
2. Dynamic Routing 
Routers automatically learn routes using routing protocols. 
Advantages 
 Automatic updates  
 Scalable  
 Better fault tolerance  
Disadvantages 
 Complex  
 Uses CPU and bandwidth

OSPF & EIGRP Concepts 
Introduction 
Both OSPF and EIGRP are dynamic routing protocols used in computer networks. 
They help routers: 
 Discover networks  
 Exchange routing information  
 Select the best path  
 Update routing tables automatically  
 
1. OSPF (Open Shortest Path First) 
Definition 
OSPF is a Link-State Routing Protocol used inside an organization. 
It uses the Dijkstra Shortest Path First (SPF) algorithm to find the shortest path. 
 
Features of OSPF 
 Open standard protocol
